# Como clonar o Renova Tudo

Siga os passos abaixo para obter uma cópia local do projeto Renova Tudo e executar o aplicativo.

## Pré-requisitos
- [Git](https://git-scm.com/downloads) instalado na máquina.
- Acesso ao terminal (Linux, macOS ou Windows com PowerShell / Git Bash).

## Passos para clonar
1. Escolha uma pasta no seu computador onde deseja guardar o código.
2. Abra o terminal nessa pasta.
3. Execute o comando:
   ```bash
   git clone https://github.com/renovatudo/renovatudo.git
   ```
   > Substitua a URL acima pela URL correta do repositório, caso seja diferente.
4. Entre na pasta criada:
   ```bash
   cd renovatudo
   ```

## Atualizar o repositório
Para baixar as alterações mais recentes depois de clonar, execute:
```bash
git pull origin main
```

## Executar o projeto
Consulte o arquivo [README.md](README.md) para verificar dependências específicas e instruções de execução.
